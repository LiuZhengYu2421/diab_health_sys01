# 智糖健康管理平台（Vue 3）· 前端对接说明

> **本文档用途：前端部署、启动、Mock/真实接口切换、认证接口对接约定。**
> 后端全部接口规范见同目录 `后端接口文档.md`。

本项目已由原生 HTML 改造为 **Vue 3 + Vite + Pinia + Vue Router + Axios** 项目，
登录/注册已**完全脱离 Dify**，改为对接自建后端（SpringBoot）。

---

## 一、快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 生产构建
npm run build
```

> 默认 `VITE_USE_MOCK=true`，使用本地 Mock 数据，无需后端即可运行演示。
> 登录/注册任意新用户名即可注册，已注册用户可直接登录。

---

## 二、Mock / 真实接口 切换

通过环境变量控制（`.env.development` / `.env.production`）：

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `VITE_USE_MOCK` | `true` | 本地 Mock 模式（localStorage 模拟用户库） |
| `VITE_USE_MOCK` | `false` | 请求真实 SpringBoot 接口 |
| `VITE_API_BASE_URL` | `/api` | 接口前缀 |
| `VITE_API_SERVER_URL` | 空 | 后端完整地址；留空时走 `VITE_API_BASE_URL` + Vite 代理 |

**对接真实后端的步骤：**
1. 启动 SpringBoot 项目（默认端口 `8080`，可通过 `server.port` 修改）。
2. 将 `.env.development` 中 `VITE_USE_MOCK` 改为 `false`。
3. 若后端端口不是 `8080`，同步修改 `vite.config.js` 中 `server.proxy['/api'].target`。
4. 重启 `npm run dev` 即可。

## 三、接口约定（请在 SpringBoot 中实现）

前端调用文件：`src/api/auth.js`（请求封装：`src/api/request.js`）

### 1. 统一响应格式

```json
{
  "code": 200,
  "message": "ok",
  "data": {}
}
```

- `code`：`200` 或 `0` 表示成功；`401` 表示未登录/登录过期（前端自动清理并跳转登录页）。
- `data`：业务数据。

### 2. 接口清单（仅认证相关 4 个）

| 方法 | 路径 | 请求体 | 成功返回 data | 说明 |
| --- | --- | --- | --- | --- |
| POST | `/api/auth/login` | `{ "username": "xxx", "password": "xxx" }` | `{ "token": "jwt...", "userInfo": {...} }` | 登录 |
| POST | `/api/auth/register` | `{ "username": "xxx", "password": "xxx", "nickname": "xxx" }` | `{ "token": "jwt...", "userInfo": {...} }` | 注册 |
| POST | `/api/auth/logout` | 无（携带 token） | `{}` | 退出登录 |
| GET | `/api/user/info` | 无（携带 token） | `{ ...userInfo }` | 获取当前用户信息 |

> 其余业务接口（医生/文章/收藏/风险/方案/建议/打卡，共 42 个）见项目根目录 `后端接口文档.md`。

### 3. userInfo 建议字段

```json
{
  "id": 1,
  "username": "zhang",
  "nickname": "老张",
  "avatar": "/img/user_icon.png",
  "desc": "智慧控糖 · 健康生活",
  "role": "user",
  "createdAt": "2026-08-12"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `role` | string | `user`（默认）/ `doctor` / `admin`，前端据此控制权限入口 |

> 前端展示优先级：`nickname > username > name > userName`；`avatar` 留空时使用默认头像。

### 4. Token 传递

前端会在每次请求的请求头自动携带：

```
Authorization: Bearer <token>
```

SpringBoot 建议使用 JWT 或 Session 校验，`401` 时返回约定格式。

## 四、前端接口封装（如需新增业务接口）

`src/api/request.js` 已封装 axios 实例（自动带 token、统一处理错误码），
新增接口时在 `src/api/` 下新建模块即可：

```js
// src/api/health.js
import request from './request'

// 获取健康档案
export function getHealthProfile() {
  return request.get('/user/health-profile')
}

// 提交打卡
export function submitCheckin(data) {
  return request.post('/checkin', data)
}
```

## 五、目录结构

```

├── vite.config.js              # Vite 配置 + /api 代理到 SpringBoot

├── .env.production             # 生产环境变量
├── public/                     # 静态资源（css / img / webfonts）
└── src/
    ├── main.js                 # 应用入口
    ├── App.vue                 # 根组件
    ├── router/index.js         # 路由 + 登录守卫
    ├── stores/user.js          # Pinia 用户状态
    ├── api/
    │   ├── request.js          # Axios 封装（token / 错误处理）
    │   └── auth.js             # 登录/注册/退出/用户信息（SpringBoot 对接点）
    ├── utils/
    │   ├── storage.js          # token / 用户信息本地存储
    │   └── alert.js            # 浮动提示
    └── views/
        ├── LoginView.vue       # 登录/注册页
        ├── LayoutView.vue      # 主框架（顶栏 + 侧栏 + 内容区）
        ├── TeamView.vue        # 专业医师团队
        ├── ScienceView.vue     # 健康科普
        ├── MineView.vue        # 个人中心
        └── PlaceholderView.vue # 建设中占位页
```
