# **一、项目介绍**

#### **1. 项目背景与简介**

在当今全球化的时代，糖尿病已然成为一个令人忧虑的全球性健康难题。随着生活方式的急剧转变，如高糖高脂饮食的普遍化、运动量的大幅减少，以及人口老龄化进程的加速，糖尿病的发病率正以惊人的速度持续攀升。世界卫生组织的数据显示，全球糖尿病患者数量已达数亿之多，并且这一数字仍在不断增加。糖尿病不仅会引发各种严重的并发症，如心血管疾病、肾病、失明等，严重威胁患者的生命健康和生活质量，还会给社会和家庭带来沉重的经济负担，包括高额的医疗费用、长期的护理成本以及生产力的损失。因此，如何科学有效地预防和治疗糖尿病，成为了全球公众和医疗界共同关注的焦点问题。

“糖尿病预治智能助手” 创新性地融合了 DeepSeek 和 Dify 的前沿智能体开发技术，精心构建了一个一站式的糖尿病预治管理体系。通过深度对接专业医学知识库，并运用 DeepSeek 大模型，能够对用户输入的健康数据进行全方位、深层次的分析，进而精准预测糖尿病风险。不仅如此，该助手还会根据用户的具体健康状况和糖尿病类型，量身定制个性化的防治方案，涵盖科学合理的饮食计划和针对性强的运动指导，助力用户有效管理病情。除此之外，还贴心地设置了与糖尿病领域专家在线交流的名医对话界面，让用户能够随时随地获得专业、权威的医疗建议。

#### **2. 项目功能特色**

- 项目依托于国家推进健康中国建设、加强慢性病管理的政策，助力提升糖尿病预防和治疗水平，推动糖尿病防治工作的科学化、规范化发展。
- 项目主要包含健康数据录入、糖尿病风险预测、个性化生活方案制定、名医在线交流、健康资讯推送、生活打卡及生活状态分析等功能。是一套业务结构清晰、流程完整的糖尿病预治智能管理平台。

#### **3. 项目技术特色**

- 项目可作为 Web 前后端开发课程的配套实训项目，基于 Vue3 生态完成前端工程化开发，通过完整的案例设计与实现，强化对 Vue3、组合式 API、Axios、组件封装等前后端交互工程化能力；
- 项目打破传统的开发方式，重塑软件开发流程，将 AI 智能编程深度融入其中，通过智能辅助项目设计、自动化代码生成和智能测试等核心环节，提高了项目质量与开发效率。这种创新模式已成为现代软件开发的主流范式；
- 项目使用 Dify 作为 AI 能力服务中台，结合 DeepSeek 大模型、向量知识库、工作流及智能体编排，实现糖尿病风险预测、个性化生活方案定制等复杂 AI 业务逻辑；
- **前端基于 Vue3 + Vite 构建，后端采用 SpringBoot 框架开发业务接口**，前后端分离架构，通过接口完成用户信息、健康记录、打卡数据等业务数据的持久化管理；
- 项目基于 VSCode 工具和 CodeBuddy 插件整合 DeepSeek 大模型，辅助智能代码开发、代码优化和测试，实现更智能、更高效的开发模式；
- 项目借助 AI 开发工具 CodeBuddy，协助设计 Web 前端界面，打破传统的前端编码方式，提升开发效率及 AI 工具使用能力；
- 项目运用 DevOps 开发运维一体化思想，使用华为云软件开发生产线 CodeArts 完成项目的全流程管理，实现需求管理、代码托管、构建部署等流程，培养综合项目管理能力；
- 项目以业务需求为导向，通过引导式教学方式，带领学生逐层分析、设计、编码、测试及优化，综合训练学生前后端分离项目工程化思维能力。

#### **4. 项目开发环境**

- 操作系统：Windows10/11、Ubuntu（开发与部署）
- 云资源：DeepSeek API
- 项目开发技术：
  - 前端：Vue3、Vite、JavaScript、CSS3、Axios
  - 后端：SpringBoot、MyBatis-Plus、MySQL
  - AI 能力：Dify 知识库搭建、工作流编排、智能体开发
- 项目开发技术工具
  - Visual Studio Code：v1.92.2（Vue 前端开发）
  - IntelliJ IDEA 2025.3.1（SpringBoot 后端开发）
  - DeepSeek
  - CodeBuddy
  - Dify 平台
- 项目开发使用模型
  - deepseek-v4-pro（用于项目架构设计、辅助文档编写、复杂问题处理，如：根据用户信息判断糖尿病患病风险）
  - deepseek-v4-flash (用于代码生成，如：根据描述实现首页数据展示代码)
  - embeddinggemma:300m-qat-q4_0（用于知识库向量化）
- 智能开发工具融入
  - 项目分析设计阶段：项目立项、项目需求分析等内容使用 DeepSeek 大模型辅助设计实现；
  - UI 界面设计阶段：使用 CodeBuddy 工具，辅助进行 UI 界面设计，工具根据自然语言直接生成 UI 界面；
  - 编码阶段：
    - 前端开发：Vue3 + Vite，DeepSeek+CodeBuddy 辅助编程，在 CodeBuddy 窗口描述功能需求，自动生成组件、页面与交互代码；
    - 后端开发：SpringBoot + MyBatis-Plus，DeepSeek+CodeBuddy 辅助编写 Controller、Service、Mapper 等业务代码；
  - 测试阶段：DeepSeek 根据项目功能生成测试用例，再根据测试用例生成 Playwright 框架的测试脚本，运行测试。
